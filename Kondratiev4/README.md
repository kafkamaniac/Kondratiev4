# Работа с анкетами

## Описание
Консольное приложение на C# для обработки анкет людей.

## Возможности
- Создание и хранение анкет.
- Проверка корректности введённых данных.
- Обработка и нормализация ФИО.
- Разделение корректных и некорректных записей.
- Сохранение результатов в текстовые файлы.

## Технологии
- C#
- .NET

## Запуск
1. Склонируйте репозиторий.
2. Откройте файл решения `.sln` в Visual Studio.
3. Запустите проект клавишей `F5` или `Ctrl + F5`.
